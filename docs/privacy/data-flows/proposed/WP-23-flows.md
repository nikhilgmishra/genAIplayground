# WP-23 data-flow rows (draft, phase C): domain reads and writes, reference business API

Drafted by WP-23 for the flows it adds; the phase C data-flows owner (WP-17) merges them into
`docs/privacy/data-flow-inventory.md`. They implement the system-of-record side of the scheduling, billing, claims,
provider-network and referral flows for a tenant whose system is connected through a reviewed ConnectorProfile and
domain binding.

Implemented and exercised against the reference business API container only (SYNTHETIC data). No tenant system has
been connected. Round 1 refix (wave C1) adds the dispatch deadline and the request digest to DF-WP23-02 to DF-WP23-04:
both are content-free (an instant and a hash) and add no new data class. Round 2 adds the fences (a request id or
external reference, an operation name and the deadline) and the legacy dispatch reservation (the reference and an
opaque per-delivery dispatch id): content-free control data, no new data class, stored by the system of record with the
change-request rows and the references (DF-WP23-03, DF-WP23-04).
