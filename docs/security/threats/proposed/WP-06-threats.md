# WP-06 proposed threat rows: connector runtime, outbound transport and module boundaries

Drafted by WP-06 (connector runtime) for the phase B threat-model owner to merge into
[`docs/security/threat-model.md`](../../threat-model.md). Row ids are provisional (`T-FO-06-nn`); the merging
owner assigns the next `T-` numbers. The boundary is every outbound call to a vendor or business system, the
credentials those calls use, the records they return, and the import graph that decides which code can make
them. Evidence is Layer 1 (real sockets to the protocol emulator) and Layer 2 (TLS, LocalStack Secrets Manager
and KMS, postgres:16); nothing runs against a vendor or AWS (NOT_CONFIGURED).

| T-FO-06-01 | Outbound request steered to an attacker host (SSRF) | T, I | A response-supplied next link, `instance_url` or redirect, a DNS answer that rebinds to an internal address, an IP literal, or a new code path calling `fetch` directly | Exact host allowlist per profile checked before I/O; IP literals and plain http refused; DNS answers classified (IPv6 is public only in 2000::/3 outside the 6to4, Teredo / 2001::/23 and documentation blocks, so an embedded loopback or private IPv4 never passes) and the connection pinned to the checked address; redirects refused; next links off-origin refused; `fetch`, `WebSocket`, DNS and raw socket modules (deep imports included) banned outside the transport by lint, the global object readable only through static non-network members (no alias, destructuring or computed key), and the same import restrictions re-checked by an independent scan in the architecture suite; the bans cover fixtures and testing helpers under src/ too (production code can import them), and the one test-only exception (the Salesforce contract-test emulator) must stay unreachable from production sources | `platform/src/connectors/http/transport.ts`, `address.ts`, `platform/src/connectors/runtime/connector.ts`, `platform/eslint.config.js` | FO-06-20, FO-06-13, SAFE-05 (`connectors/runtime.test.ts`, `src/connectors/http/transport.test.ts`, `test/architecture/lint-rules.test.ts`, `test/architecture/import-graph.test.ts`) | Existing Salesforce adapter, notification sender and OTLP exporter still use their own clients until WP-07 moves them | IMPLEMENTED |
