# WP-11 threat rows (draft, phase C): media worker, CallBinding issuance and recovery, recording control

Drafted by WP-11 for its boundary: the LiveKit Agents worker and its call handling (`media/src/worker`, `lifecycle`,
`playback`, `codecs`, `binding`, `recovery`, `recording`), the CallBinding contract and processing readout
(`platform/src/protocol/call-binding.ts`), the binding store and issuance service with the runtime credential verifier
and the media-plane lookup (`platform/src/calls/binding`), the gateway media routes
(`platform/src/gateway/http/media-routes.ts`) and the local egress configuration (`deploy/local/livekit`). The phase C
threat-model owner (WP-17) merges them into `docs/security/threat-model.md` section 8 with FT ids. All rows: environment
`NOT_CONFIGURED` (AIN-46 security review of the self-hosted media plane before non-local use).
