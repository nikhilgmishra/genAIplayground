# WP-08 threat rows (draft, phase C): model port, provider adapters, model egress classes, emulator

Drafted by WP-08 for its boundary (the model port and provider adapters in `platform/src/models/port` and
`platform/src/models/adapters`, the model endpoint classes of `platform/src/privacy/egress.ts`, the protocol emulator in
`platform/test/emulators/models` and `deploy/local/services/model-emulator.compose.yaml`). The phase C threat-model owner
(WP-17) merges them into `docs/security/threat-model.md` section 8 with FT ids. They refine FT-08 (endpoint substitution),
FT-11 (cost, quota or hang exhaustion) and FT-12 (secret context reaching a model) for the adapter layer; the registry
and approval rows of FT-08 and FT-09 stay with WP-09, the harness rows of FT-10 to FT-12 with WP-10.
